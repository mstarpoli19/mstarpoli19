## Selected work

### [Repo Eval Workbench](https://github.com/mstarpoli19/repo-eval-workbench)

A Python toolkit for read-only repository checks and offline evaluation of structured code reviews. It includes synthetic test cases, precision/recall/F1 scoring, evidence-level reports, and CI. No model API or runtime dependencies required.

**Look inside:** [evaluation contract](https://github.com/mstarpoli19/repo-eval-workbench/blob/main/docs/evaluation-contract.md) · [tests](https://github.com/mstarpoli19/repo-eval-workbench/tree/main/tests) · [example results](https://github.com/mstarpoli19/repo-eval-workbench/blob/main/reports/example-evaluation.md)

### [Teenage Grandma Website](https://github.com/mstarpoli19/Teenage-Grandma-Website)

A storefront prototype built with HTML, CSS, vanilla JavaScript, and Node.js. Features include product browsing and filtering, client-side routing, a persistent cart, and a mock checkout.
